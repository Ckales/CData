# Inno Setup translation

`ChineseSimplified.isl` is copied without modification from Inno Setup 6.7.1:
https://github.com/jrsoftware/issrc/blob/cfdf48923178df4b4f040e038b423aa555a61ffc/Files/Languages/Unofficial/ChineseSimplified.isl

It supports Inno Setup 6.5.0+. Bundling it keeps Windows packaging independent
of the languages installed alongside `ISCC.exe`. Keep the upstream notices
and `LICENSE.txt` when updating the translation.
